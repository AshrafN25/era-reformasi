# Era Reformasi Indonesia 1998

Website sejarah Era Reformasi Indonesia dengan desain editorial modern.

## Struktur Folder

```
era-reformasi/
├── index.html          # HTML markup (tanpa inline CSS/JS)
├── css/                # Semua stylesheet
│   ├── base.css        # Variables, reset, typography
│   ├── nav.css         # Navigation bar
│   ├── hero.css        # Hero section
│   ├── latar.css       # Latar belakang section
│   ├── timeline.css    # Timeline section
│   ├── tokoh.css       # Tokoh section
│   ├── hasil.css       # Hasil perubahan section
│   ├── dampak.css      # Dampak section
│   ├── presiden.css    # Era presiden section
│   ├── kesimpulan.css  # Kesimpulan section
│   └── footer.css      # Footer
└── js/
    └── main.js         # Scroll animations (IntersectionObserver)
```

## Teknologi

- **HTML5** — Semantic markup
- **CSS3** — Vanilla CSS dengan custom properties (CSS variables)
- **JavaScript** — Vanilla JS untuk scroll animations
- **Fonts** — Google Fonts (Cormorant Garamond, Lora, DM Mono)

## Fitur

- Fully responsive design
- Scroll-triggered fade-in animations
- Timeline dengan stagger effect
- Dark/light section alternation
- Smooth scrolling navigation
- Custom scrollbar styling

## Cara Menggunakan

1. Buka `index.html` di browser modern (Chrome, Firefox, Edge, Safari)
2. Tidak perlu build tools atau dependencies
3. Semua assets sudah self-contained

## Browser Support

- Chrome/Edge 90+
- Firefox 88+
- Safari 14+

## Lisensi

Materi edukatif untuk pembelajaran sejarah Indonesia.
